Antminer S9,T9+

HOW TO INSTALL

If you see the message: can not find signature when you flash the asic with VNISH firmware you need to take off bitmain software protection. This message means that your asic has BITMAIN firmware 2019 year that has overwrite protection

If you have BITMAIN firmware june 2019 or earlier you can remove the protection using the “signature” file and then flash vnish firmware. If you have firmware 31 July 2019 you can remove the protection using the “signature_31july” file, also installing our firmware is possible via the SD card (all files you can download from this page) You can check the firmware version in the System – file system version

If during the flashing process via the SD card you see that 2 lamps (green and red) on the control board are on and don’t blink, then most likely your control board is infected with the ANTBUILD virus, you need to use a special ANTBUILD_RECOVERY image to block the virus (Attention, this image can only be used on infected asics with the antbuild virus)

FIRMWARE CHANGELOGS

 

Release 3.9.1

 

1) A new tuning algorithm has been implemented, achieving high firmware stability.

2)Tuning works 50% faster and more accurately.
3) Fixed an error with the generation of a large number of HW errors.
4) Significantly accelerated the interface on chips.
5) Optimization of dev fee (ability to select one of 3 regions: Europe, Russia, backup)
6) Fixed the problem with hotel fee via stratum+tcp. For hotel fee you can use any pools (we recommend AntPool, ViaBTC) that can set difficulty in the password d=512, d=1024.
7) Fixed the problem of remote access on Kinetics (directly via DNS name without VPN).
8) Increased tuner log to 50 event lines.
9) Fixed rejects. Rejects are now written in the miner log.

 

Release 3.9.0

 

1) A new tuning algorithm has been implemented.
2) Fixed an error with the generation of a large number of HW errors.
3) Added a signature for protection against viruses.

4)Added profiles that are activated without tuning.

5)Added the ability to save a profile without new tuning when changing other settings.

6)Added support for anthill.farm monitoring.

 

Release 3.8.8

 

1) Fixed a fan error at low speeds.
2) Fixed an error in the function of searching for ASICs on the farm.

3) Added the HOTEL FEE option (where you can redirect part of the hashrate to pay for electricity, equipment placement or maintenance service for miners).
4) Added the Find Miner function to the config multiplier to search for a larger number of miners at once.

 

Release 3.8.7.1

 

1) Fixed errors with enabling/disabling SSH.
2) Fixed an error where the ASIC would not start mining when only one stratum was specified in the settings.
3) Fixed the enabling of manual fan control.
4) Added #xnsub for NiceHash.

 

Release 3.8.7

 

1) Overall stability and driver refactoring.
2) Quick saving of settings and web GUI response.
3) Added chip target temperature function.
4) Improved the auto-tuning algorithm.
5) Activated the multiplier for mass configuration distribution.
6) Added a function for mass password changes.
7) Added a function for mass enabling/disabling SSH.
8) Improved profiles and added power consumption values.
9) Added a quiet start option.
10) Added a standby mode option when the internet connection is lost.
11) Added fan error output to the log.
12) Fixed an error where HW reduction would not turn off.
13) Fixed an error where the miner would not shut down at the set temperature.

 

Release 3.8.6

 

1) Overall stability

2) Added the ability to choose between a full ASIC restart and a restart of only the cgminer in the tuning.

3) In addition to the automatic virus checking system, we added manual checking and disinfection in the Security section, including the new AntBuild virus.

4) Fixed connection to Anthill.farm monitoring.

5) Added the Find Miner function to the config multiplier to search for a larger number of miners at once.

6) Changed the log file download format to .txt.

7) New “sleep mode” function — when enabled, mining stops and fans drop to minimum speeds. The function is available in the config multiplier.

8) Fixed the issue with the DevFee error exit.
