версия 1.3.5-stable

⌨ Расширенная поддержка майнеров и оборудования:

  • Новые модели: Добавлена поддержка Antminer U2L9H и Antminer S21++.
  • Поддержка Xilinx: Добавлена поддержка Antminer S19-126 на платах управления Xilinx.
  • Новые блоки питания: Добавлена поддержка моделей блоков питания 0x67 и 0xc5.

⚙ Новые функции и улучшения:

  • Интерфейс вкладки «Обслуживание»: Функции резервного копирования, восстановления резервной копии, сброса до настроек по умолчанию и отката к заводским настройкам перемещены на отдельную вкладку «Обслуживание» в веб-интерфейсе.
  • Автономный майнинг: Исправлен и стабилизирован режим работы автономного майнинга.

🔧 Исправления ошибок и улучшения

Обнаружение оборудования:

  • Автоматическое определение ASIC: Исправлены проблемы с определением модели для Antminer S19 Pro (114 чипов), T19, S19, S19 Pro Hydro (120), Antminer S21 подмодель BHB68603P.

Настройка и предустановки:

  • Улучшения автонастройки: Исправлены и оптимизированы алгоритмы автонастройки для нескольких моделей майнеров.
  • Именование предустановок: Исправлены некорректные названия предустановок для Antminer S21e Hydro, T19 и S19j+.
  • Удаление предустановок: Удалены предустановки, превышающие 346 TH, для Antminer S21 Hydro.

📈 Система и журналы:

  • Очистка журналов Xilinx: Исправлена процедура «удаления стандартных журналов» на платах управления Xilinx для обеспечения чистого удаления журналов.

💻 Изменения в API:

  • Удаление маршрута: Маршрут /layout был навсегда удален из API.
  • Удалены поля ‘asic_boost’, ‘modded_psu’: Поле configuration/API было навсегда удалено.

  • Antminer S19k Pro: BHB56907
  • Antminer S21+: A3HB70702
  • Antminer S21+ Hydro: H6HB70702, H6HB70704
  • Antminer S21 Pro: A3HB70603
  • Antminer S21 XP: A3HB70502, A3HB70503
  • Antminer S21 XP Hydro: H6HB70502
  • Antminer S19 XP+ Hydro: HHB68702, HHB68703

🆕 Расширенная поддержка блоков питания

  • Добавлена поддержка типов блоков питания: 0xc4, 0x69

⚙️ Новые функции и улучшения

  • Термозащита по умолчанию для гидро/иммерсионного охлаждения: Для обеспечения долговечности оборудования критическая температура по умолчанию для всех моделей с гидро и иммерсионным охлаждением теперь устанавливается на 80°C при установке прошивки.
  • Расширенная локализация: Добавлена поддержка двух новых языков: португальского (pt) и грузинского (ka).
  • Расширена задержка запуска и возобновления майнинга: Задержка запуска майнинга и возобновления майнинга (настраиваемая в секундах). Это обеспечивает контролируемый поэтапный запуск для стабильности питания, независимо от того, включается ли майнер впервые или возобновляет работу после паузы.
  • Откат к заводским настройкам: Добавлена опция автоматического удаления системных журналов при выполнении операции «Откат к заводским настройкам».
  • Защита от перегрева: Реализован критически важный мониторинг температуры блока питания. Теперь система будет автоматически понижать/повышать предустановленные значения для предотвращения перегрева блока питания.
  • Безопасные отключения: Майнер теперь немедленно переходит в «состояние ошибки» при обнаружении ошибок датчиков или перегрева.
  • Оптимизация автотюна: Улучшены алгоритмы автотюна для повышения стабильности и эффективности.
  • Управление напряжением: Уменьшены смещения напряжения во время настройки частоты для более точного управления питанием.
  • Улучшена диагностика: Обновлена логика проверки датчиков температуры и исправлены распространенные проблемы, связанные с глобальными настройками приложений.
  • Исправления стабильности: Устранена ошибка «Случайный штраф DevFee».

🔧 Новые параметры конфигурации

  • Работа в автономном режиме: позволяет майнеру продолжать работу без подключения к интернету (Примечание: хешрейт, полученный в автономном режиме, не отправляется на пулы).
  • Отложенное возобновление: добавлена опциональная задержка перед возобновлением майнинга.
  • Расширенное управление питанием: новая команда регулирования мощности чипов: позволяет пользователям вручную снижать мощность майнинга. Например, установка регулирования мощности на 50% снизит мощность майнера с 200TH до 100TH, что позволит немедленно сэкономить электроэнергию без остановки майнера.
  • Настройки для гидросистем: добавлена опция «Минимальная температура воды для запуска» для систем жидкостного охлаждения.
  • Новый виджет охлаждения: добавлен отдельный виджет на панели управления для систем гидро- и иммерсионного охлаждения.
  • Расширенная логика: Добавлена опция «Повторный запуск автотюна при обрыве цепочки». Добавлена опция «Разрешить отключение платы без PIC-контроллеров».
  • Временные метки настройки предустановок: интерфейс теперь отображает дату завершения автотюна по пресетам. Примечание: Это относится только к сеансам автотюна, выполненным в этой версии прошивки или более поздних. Предустановки, настроенные в предыдущих версиях, не будут отображать дату.
  • Ограничение мощности: Добавлена новая функция ограничения мощности майнера. Теперь майнер будет строго придерживаться заданным пользователем ограничения мощности, автоматически снижая разгон (частоту/напряжение), если потребление энергии попытается превысить лимит.

🔧 Исправления ошибок

  • Синхронизация NTP: Добавлены новые пулы серверов времени (pool.ntp.org) для обеспечения более надежной синхронизации системных часов и более быстрого подключения к майнинговым пулам.
  • Защита от сброса к заводским настройкам: Исправлена проблема, из-за которой серийный номер устройства случайно удалялся во время сброса к заводским настройкам.
  • Исправлены проблемы, связанные с клонированием настроек майнера.
  • Исправлена ошибка зависания панели управления, возникающая при запросе к сторонним службам мониторинга.
  • Сохранение конфигурации: Исправлена проблема, из-за которой изменения конфигурации майнера не сохранялись корректно.
  • Сетевые настройки: Исправлена проблема с чтением и отображением сетевых настроек. Это гарантирует корректное получение IP-адресов, конфигураций шлюзов и других сетевых параметров из системы и их корректное отображение в веб-интерфейсе.

⚠️ Устаревшие и удаленные функции

  • Удалено: опция более высокого смещения напряжения.
  • Очистка пользовательского интерфейса: настройки виджетов удалены из интерфейса для более удобного использования.
  • Удалена настройка «Модифицированный блок питания»: возможность ручного выбора модифицированного блока питания удалена из конфигурации.

💻 Изменения в API

  • Миграция метода: метод find-miner теперь устарел.
  • Новый маршрут: добавлен метод ‘locate-miner’. Этот новый метод включает параметр для явного включения или выключения индикатора местоположения майнера (светодиода), обеспечивая лучший контроль через API.
  • Новый маршрут: добавлен маршрут ‘boards’ в API для более детального получения данных хэшборда.
  • Новый маршрут: ‘/mining/throttle’ добавлен специальный маршрут для управления новой функцией регулирования мощности/масштабирования энергопотребления.
  • Удаление маршрута: Маршрут ‘/chips’ был окончательно удален из API.
  • Переименование поля: Для повышения ясности поле API ‘remain_stopped_on_reboot’ было переименовано в ‘restore_miner_state_on_reboot’.
